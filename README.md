## Mark Lester J. Real — Portfolio

4th-year Computer Science student and aspiring Software Engineer based in the Philippines.

### Stack

- **React 19** + **Vite 8**
- Plain CSS (BEM naming, no frameworks)
- `react-icons` for technology logos

### Scripts

```bash
npm install   # install dependencies
npm run dev   # start dev server
npm run build # production build
npm run lint  # eslint
npm run preview # preview production build
```

### Project structure

```
src/
├── main.jsx
├── index.css              # global: reset, fonts, background
├── App.jsx                # composes sections
├── App.css
├── data/                  # content (profile, projects, timeline, languages, technologies)
└── components/
    ├── Header/
    ├── Hero/
    ├── TechSection/
    ├── TechMarquee/
    ├── SectionHeading/    # shared heading pattern
    ├── ContentSection/    # shared section layout
    ├── About/
    ├── Projects/
    ├── Timeline/          # Experience + Education
    ├── Contact/
    └── Footer/
```
